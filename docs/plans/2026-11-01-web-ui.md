# Embedded photo gallery and Jetson monitoring implementation plan

Approved spec: user's complete plan in this conversation, 2026-11-01.
Goal: Python3.10 FastAPI/Jinja2/Bootstrap embedded in existing controller; Chinese
square-corner white UI without icons/emojis. Read-only gallery of existing
annotated JPEG+JSON; tegrastats charts with 2s sampling/900s/450 sample maximum.
No new inference routes, uploads, deletions, printer controls, database, GPU
imports, or one-hour tests. LAN 0.0.0.0:8000, no login. Preserve model, threshold,
spaghetti/warping/error, dry_run=true, and boot activation policy.

### Task 1: Secure gallery and pages
Files: web/gallery.py, web/app.py, web/templates/, web/static/, web/requirements.txt,
tests/test_web_gallery.py. Exact dependencies FastAPI0.162.0 Uvicorn0.54.0
Jinja2 3.1.6; vendor Bootstrap5.3.8 CSS and Chart.js4.6.1 UMD with license/hash.
GET / redirects /photos; GET /photos?page=1 (24 newest first); GET
/photos/{filename}; GET /media/{filename}; GET /jetson; GET /api/jetson.
PhotoStore(root).list_page(page), detail(filename), open_image(filename).
Existing boxes remain baked into photos; JSON supplies table only. Broken/missing
JSON displays unavailable, images remain readable. Path traversal and escaping
symlinks forbidden. Autoescape labels. Lazy image FileResponses, no image cache.
Write fixture tests first, run RED, implement, run GREEN and commit.
Expected: pagination/detail/empty/metadata errors/XSS/path tests PASS.

### Task 2: Single bounded telemetry sampler
Files: web/telemetry.py, web/static/jetson.js, tests/test_web_telemetry.py.
parse_tegrastats(line) -> CPU/GPU percent, RAM/SWAP used+total MB, temperatures.
CPU averages online cores. Missing fields null, not zero. TelemetrySampler.start,
stop,snapshot shared by FastAPI lifespan. One owned subprocess with argv
/usr/bin/tegrastats --interval 2000, no shell/sudo/global stop. deque max450;
expire >900s using monotonic; status stale >6s, retry <=once/5s. Samples expose
age_s on reads, chart x=-age_s; values unavailable when stale, preserve history
with null gaps. Startup/shutdown idempotent, stop interrupts blocked read and
reaps owned process; multiple tabs create no processes. Chart animation disabled.
Write parser/history/real child lifecycle tests RED; implement GREEN and commit.
Expected: fixture parsing, 900s expiry/450 bound, stale/retry/single child PASS.

### Task 3: Embedded controller lifecycle
Files: web/server.py, main.py, config.json.example, tests/test_web_lifecycle.py.
EmbeddedWebServer(root,host,port) runs single Uvicorn on own background thread,
no reload/workers/signals. Start before GPU worker; replace preexec_fn=os.setsid
with start_new_session=True. Missing web config disables, example enables LAN.
Entire controller startup/run cleanup is finally-protected, partial components
closed once, web/metrics failures logged without disabling print monitoring.
Owned web and sampler stop on all exits including early GPU/auth failures.
Write tests for ordering, failure cleanup, occupied port, repeated stop, old config
and Popen kwargs before implementing. Expected: all new+existing tests PASS.

### Task 4: Hardware, review and deployment
Local browser desktop/mobile/metadata/table/charts/offline assets checks. Nano
short offline single-UDS-client serial baseline/web-enabled benchmark (no real
printer commands): extra controller+tegrastats RSS <=100MiB, P95 <=110% baseline.
Final fresh read-only whole-branch review, one RED/GREEN fix wave if needed.
Back up remote code/config, preserve newer local model changes/untracked sidecars.
Install only web deps in Python3.10 venv, not worker3.6; deploy code and static
assets via hash-checked fast-forward. Enable web config keeping rest equal;
start existing controller in dry-run, confirm LAN pages and real sensor values.
Preserve boot setting (remote unit is currently absent; do not enable autostart).
Merge locally after green suite; record measurements, URL and rollback paths.
Expected: short smoke PASS, bounded processes/memory, no extra GPU imports.
